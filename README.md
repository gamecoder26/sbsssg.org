# SBSSS — CodeIgniter to Static HTML

This folder is a static frontend conversion of the public-facing CodeIgniter views.

## Pages
- index.html
- aboutus.html
- mission.html
- aim.html
- ourinstitution.html
- facilities.html
- admission.html
- download.html
- noticebord.html
- contact.html

## Assets
The original `frontassets` directory is retained so the existing design, images, CSS and JavaScript continue to work.

## Important
The original CodeIgniter application uses PHP/database functionality for admissions, contact enquiries and notices. Those server-side operations cannot exist in a pure static HTML site. The converted admission/contact forms therefore use browser email fallback and the notice board is static.
